Architecture

How It Works

NexTopo runs as an independent C++20 engine process that communicates with a Blender add-on purely through file and stdio exchange — never linked in the same process. This keeps the engine fully decoupled from Blender's own Python runtime.

Fully Offline

All processing happens locally on your machine — no mesh data ever leaves your computer.

Key Advantage

Determinism as a Hard Guarantee

The same input mesh and the same seed always produce an identical, bit-exact result — whether the engine runs on one thread or all available cores.

🎯

Production-Grade Repeatability

Built for team pipelines where the retopology result must be identical across every machine in the studio.

🧮

Seed-Locked Solver

Every run is seeded and single-threaded at the solver level, so the outcome never drifts between runs.

💡 Determinism is a rare trait in retopology tools — most solutions return a slightly different result on every run.

Requirements

Compatibility

  • Blender 5.2 LTS (target version)
  • Minimum supported version: Blender 4.2.0
  • Windows only
  • Fully offline processing, no network calls
  • Bit-identical output across thread counts
